# Moods Restaurant

A modern and responsive restaurant website designed to provide a complete digital experience for discovering the restaurant, exploring its menu, making appointments, and interacting with its content.

## Live Demo

[View Live Demo](https://ii3boody.github.io/Moods-Resturat/)

## Overview

Moods Restaurant is a multi-page frontend project built with a focus on clean UI, responsive layouts, and an intuitive user experience.

The website provides visitors with essential restaurant information while allowing them to explore the menu, view reviews, make appointments, and interact with different sections of the website.

## Features

- Responsive design across desktop, tablet, and mobile devices
- Modern restaurant-focused UI
- Home page with restaurant highlights
- About page
- Interactive menu section
- Appointment booking interface
- Shopping cart functionality
- Customer reviews section
- Contact page
- User registration page
- Sign-in page
- Responsive navigation
- Social media integration
- Image and video content
